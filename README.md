# NextDoor

NextDoor is a service booking platform that connects users with verified service providers for various home services like plumbing, electrical work, and more. The platform ensures seamless booking, secure payments, and a user-friendly experience.

## Features
- **Easy Service Booking**: Find and book service providers quickly.
- **Verified Providers**: Ensures trusted and skilled professionals.
- **Secure Payments**: Integrated payment interface.
- **Instant Payout (Future Enhancement)**: Providers receive instant payouts after job completion.

## Project Structure
```
NextDoor/
│-- frontend/      # React-based frontend
│-- backend/       # Node.js, Express, and MongoDB backend
│-- README.md
```

## Tech Stack
### Frontend (React.js)
- React with Tailwind CSS for UI
- Context API for state management
- React Router for navigation

### Backend (Node.js & Express)
- Node.js with Express framework
- MongoDB database
- JWT authentication for security

## Installation & Setup
### 1. Clone the repository
```sh
$ git clone https://github.com/ManoharBari/NextDoor.git
$ cd NextDoor
```

### 2. Setup Frontend
```sh
$ cd frontend
$ npm install
$ npm start
```

### 3. Setup Backend
```sh
$ cd backend
$ npm install
$ npm start
```
